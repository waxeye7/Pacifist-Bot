# Speedrun gauntlet

Adapted from `market-bot/gauntlet`. Paste **`HARD-PROMPT.md`** to start.

True north: **mean ticks spawn → RCL8**.
Fast loop: **spawn → RCL2 / RCL3 / RCL4** so we get many A/Bs per day.

A keep that speeds RCL3 by skipping a structure we still need at RCL8 is a **SEND BACK**. Delay-then-build (leftover 5 after storage) is legal. Never-build is not.

- `CRITIC.md` / `WORKBENCH.md` / `ROSTER.md` — law the prompt expects
